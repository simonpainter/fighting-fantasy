# Contributing

Thanks for your interest in improving **fighting-fantasy**.

## Quick start

1. Fork the repository and clone your fork.
2. Create a branch for your change.
3. Make focused changes with clear commit messages.
4. Run the test suite:

```bash
python3 -m unittest discover tests -v
```

5. Open a pull request with context on what changed and why.

## Development guidelines

- Keep changes focused and avoid unrelated refactors.
- Follow existing code style and naming conventions.
- Add or update tests for behavior changes.
- Update documentation when functionality or workflows change.

## Pull requests

Please include:

- A clear summary of the change
- Linked issue(s), if applicable
- Notes on testing performed

For substantial changes, open an issue first so we can align on approach.
